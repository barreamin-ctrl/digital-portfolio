# Digital Portfolio

Välkommen till vårt repo! Det här är en digital portfolio som vi bygger för kursen GIK299.

Här samlar vi allt på ett ställe: vilka vi är, vad vi kan, vilka projekt vi har jobbat med och hur man får kontakt med oss.

## Sidor på webbplatsen
- **Hem (`index.html`):** Välkomstsida med en kort intro.
- **Projekt (`projekt.html`):** Visar upp vad vi har skapat.
- **Kompetenser (`kompetenser.html`):** Våra tekniska kunskaper.
- **Utbildning (`utbildning.html`):** Vår bakgrund och studietid.
- **Kontakt (`kontakt.html`):** Så når du oss.

## Tekniker vi använder
- **HTML5** för struktur
- **CSS** (med BEM-tänk för klasserna) för design
- **JavaScript** för lite logik och interaktivitet
- **Git & GitHub** för att jobba tillsammans med koden

## Om projektet
Vi har hjälpts åt att få ihop det här från grunden med fokus på ren kod, bra struktur och att det ska vara lätt att koda vidare på tillsammans.
